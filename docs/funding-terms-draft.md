# 資金・給付条件の整理（法務確認待ち／未施行）

- 構想: 全人類を対象とする理念。本人確認・重複防止・対象条件は未確定。
- 給付予定: 毎月1日、確保した適法な原資の範囲で対象者へ均等配分。高配当の保証なし。
- GDP比・利用率・予算上限: 計算式と指標の出典は未確定。
- 利用者資金: 預り金・出資金・寄付の区分、返還条件、損失負担、分別管理を専門家と確認するまで受入れ・運用・給付原資への組入れを行わない。規約の同意だけでは許認可の代わりにならない。
- 補正予算: 個別制度の交付決定、使途条件、実際の受領の確認が必要。オンチェーン研究会の発表は受給承認ではない。
- 表示: 補正予算は受領確認済み金額、UBI総額は給付実績の累計。現時点はともに0円。シミュレーション残高、未実現利益、ローカル台帳、利用者元本から自動加算しない。
- 資金が貯まっただけではUBI給付実績を増やさない。実際の給付確認が必要。
- 不足時: 実行前に再計算し、同じ対象条件の人には同率調整。未承認の預り金で補填しない。
- 現在: 実口座未接続、資金受入れ・売買・送金無効。本草案は提供中の金融契約ではない。
