# QAN Implementation Note

The QAN templates in the UWW-SN / UBICHAIN project package are **provisional design documents**, not a verified language implementation.

The initial structure follows syntax fragments supplied by the project owner. Before production use, the project needs:
- a versioned grammar and lexical rules;
- a parser and validator;
- a runtime / execution model;
- a module and import specification;
- a permission and sandbox model;
- conformance tests and example fixtures;
- error reporting and version compatibility rules.

Until those exist, QAN files should be treated as human-readable configuration/specification drafts. Do not execute them as trusted code or use them to control production systems.
